Тема:        Реалізація фотогалереї на основі локальних зображень
Проєкт:      restik (клієнтська частина — React + Vite)
Дата:        11.06.2026

================================================================================
1. МЕТА РОБОТИ
================================================================================

Розробити вкладку «Фотогалерея» на веб-сайті, яка відображає лише власні
зображення, збережені локально в папці /public. Галерея не повинна показувати
заглушки, випадкові зовнішні зображення чи порожні/биті квадрати.

Рішення має бути виключно фронтендним — без використання бекенду, бази даних
або серверної логіки.

================================================================================
2. ПОСТАНОВКА ЗАДАЧІ
================================================================================

  • Завантажувати зображення безпосередньо з папки /public
  • Коректно відображати їх у галереї
  • Показувати лише існуючі локальні файли
  • Уникати битих зображень та запасних заглушок (placeholder)

================================================================================
3. ТЕХНІЧНЕ РІШЕННЯ
================================================================================

Оскільки браузер не може самостійно переглядати вміст файлової системи
сервера, для чисто фронтендного підходу використано таку схему:

  1. Скрипт generate_gallery_manifest.cjs (на етапі запуску/збірки) сканує
     папку client/public та формує файл gallery-manifest.json зі списком
     наявних зображень.

  2. React-компонент GalleryController.tsx завантажує цей manifest через
     fetch і відображає лише ті файли, які реально існують.

  3. Файли з пробілами в назві (наприклад, «image 1.svg») коректно
     кодуються в URL.

  4. Якщо зображення не завантажується — воно автоматично прибирається
     з галереї через обробник onError (без показу порожніх квадратів).

  5. Заглушки (sample1.svg, sample2.svg), службові файли (vite.svg,
     favicon.ico) та manifest-файли виключаються зі списку.

Схема роботи:

  [client/public/]  →  [скрипт сканування]  →  [gallery-manifest.json]
                                                        ↓
                                              [GalleryController.tsx]
                                                        ↓
                                              [Вкладка «Фотогалерея»]

================================================================================
4. СТРУКТУРА ФАЙЛІВ
================================================================================

Основні файли реалізації:

  client/src/components/GalleryController.tsx
      — React-компонент галереї (сітка зображень + перегляд у повному розмірі)

  client/scripts/generate_gallery_manifest.cjs
      — скрипт формування списку зображень з папки public

  client/public/gallery-manifest.json
      — згенерований список локальних зображень для відображення

  client/public/image 1.svg
  client/public/image 2.svg
  client/public/image 3.svg
  client/public/image 4.svg
      — власні зображення користувача

  client/src/App.tsx
      — підключення компонента на вкладці «Фотогалерея»

  client/package.json
      — npm-скрипти для автоматичної генерації manifest перед запуском

================================================================================
5. ВМІСТ gallery-manifest.json
================================================================================

[
  "image 1.svg",
  "image 2.svg",
  "image 3.svg",
  "image 4.svg"
]

================================================================================
6. ПОРЯДОК ЗАПУСКУ ТА ПЕРЕВІРКИ
================================================================================

  1. Відкрити термінал у папці client.

  2. Встановити залежності (якщо ще не встановлені):
         npm install

  3. Запустити проєкт:
         npm run dev

     (скрипт автоматично оновлює gallery-manifest.json перед стартом)

  4. Відкрити сайт у браузері за адресою, яку покаже Vite
     (зазвичай http://localhost:5173).

  5. Перейти на вкладку «Фотогалерея».

  6. Переконатися, що відображаються лише 4 локальні зображення
     без заглушок і битих елементів.

================================================================================
7. ДОДАВАННЯ НОВИХ ЗОБРАЖЕНЬ
================================================================================

  1. Скопіювати файли зображень у папку client/public
     (корінь або будь-яка підпапка).

  2. Перезапустити npm run dev
     або виконати вручну:
         npm run generate-gallery-manifest

  3. Оновити сторінку в браузері — нові зображення з’являться в галереї.

Підтримувані формати: .png, .jpg, .jpeg, .webp, .gif, .svg, .avif

================================================================================
8. РЕЗУЛЬТАТ РОБОТИ
================================================================================

  ✓ Реалізовано фронтендну фотогалерею без бекенду та бази даних
  ✓ Зображення завантажуються лише з локальної папки /public
  ✓ Відображаються тільки існуючі файли з manifest
  ✓ Заглушки (sample*.svg) та службові файли (vite.svg) виключені
  ✓ Биті зображення не показуються — прибираються автоматично
  ✓ Реалізовано перегляд у повному розмірі з навігацією (‹ ›, Escape)

================================================================================
9. ВИСНОВКИ
================================================================================

У ході роботи було створено повністю фронтендне рішення для відображення
локальної фотогалереї. Підхід з генерацією manifest-файлу на етапі запуску
дозволяє обійти обмеження браузера щодо читання директорій і гарантує, що
на сторінці з’являються лише реально існуючі зображення з папки public.

Завдання виконано повністю.
